# DTA Now Playing
OBS now-playing overlay for DagmarTheAgile, targeting YouTube Music and Suno.

## v0.1
- DTA-styled transparent OBS overlay
- YouTube Music metadata reader
- Suno metadata reader scaffold
- Chrome/Edge Manifest V3 extension

## OBS target
1920×1080. The card is designed for the lower-right corner.

## Install extension for testing
1. Download/clone this repository.
2. Open Chrome/Edge Extensions.
3. Enable Developer mode.
4. Choose **Load unpacked**.
5. Select the `extension` folder.

The next step is the local transport bridge that carries extension metadata into the OBS browser source reliably.
